Galerie

Běží lokální náhled ze složky na disku. Změny se uloží rovnou do souborů a na web se dostanou až s dalším nahráním do repozitáře.

Na tomhle zařízení je uložený přístup k .

Klíč se uloží zašifrovaný tímhle heslem jen v tomhle prohlížeči. Příště stačí heslo.

Kde vzít přístupový klíč
  1. Na GitHubu otevřete Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Pojmenujte ho třeba „Správa galerie“, platnost dejte rok.
  3. Repository access: Only select repositories a vyberte repozitář galerie.
  4. Permissions → Repository permissions → Contents: Read and write. Nic dalšího není potřeba.
  5. Klíč zkopírujte sem. GitHub ho ukáže jen jednou.

Klíč umí měnit jen tenhle jeden repozitář. Kdyby se ztratil, na stejném místě ho jedním kliknutím zrušíte.
